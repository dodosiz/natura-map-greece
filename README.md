# Natura Map Greece

An interactive map of Greece's Natura 2000 protected sites. The project includes a data pipeline, a read-only API, and a React map.

## Run locally

Requirements: Python 3.10+ and Node.js 18+.

Build the database (run from the repository root):

```sh
cd etl
pip install -r requirements.txt
python -m natura_etl
```

Start the API and frontend in separate terminals:

```sh
cd api
pip install -r requirements.txt
uvicorn app.main:app --port 8000
```

```sh
cd web
npm install
npm run dev
```

Open the frontend at <http://localhost:5173>. The API is at <http://localhost:8000>; interactive documentation is at `/docs`.

## Project layout

- `etl/` downloads and processes source data into `data/natura.db`.
- `api/` serves the database through the `/api` endpoints.
- `web/` provides the React and Leaflet map.

The database is generated by the ETL and is not committed. The API accepts `NATURA_DB_PATH` to select a database file; the frontend dev server proxies `/api` to the local API.

## Checks

- ETL: `cd etl; pytest`
- API: `cd api; pytest`
- Frontend: `cd web; npm run build`
