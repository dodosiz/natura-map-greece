# Security Policy

## Supported versions

Security fixes are focused on the latest state of the default branch. The
project does not currently publish versioned releases, so older revisions are
not guaranteed to receive security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities using GitHub's **Report a
vulnerability** feature on this repository's Security tab. Private
vulnerability reporting is enabled, so the report is sent privately to the
maintainers.

Please do not report security vulnerabilities in public issues or pull
requests. Include enough detail to help us assess and reproduce the issue,
such as the affected component, impact, prerequisites, and reproduction steps.
Avoid including real secrets or personal data in a report.

The maintainers will review reports and coordinate any necessary fixes and
disclosure with the reporter. No fixed response or remediation time is
currently guaranteed.

## Scope

This policy covers security issues in this repository's application code,
including the data pipeline, API, web application, and deployment
configuration. Vulnerabilities in third-party services, datasets, or map
providers should be reported to their respective maintainers.
